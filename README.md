# Stardust Clicker

A browser clicker game in a single file. Open `index.html` in any browser to play.

- Click the star to collect stardust (crits give 10×)
- Buy generators for passive income and upgrades to multiply it
- Catch the comets that sometimes appear for a big bonus
- 12 achievements to unlock
- Progress saves automatically, and you earn half your normal rate while away (up to 8 hours)
